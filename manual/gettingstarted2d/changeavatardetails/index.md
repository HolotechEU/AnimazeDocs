# Change the avatar details (icon, description & name)

You can find your avatar’s icon in the avatar gallery. To view your avatar's name and description, click on the **Info** button that appears in the top right corner when your avatar is previewed in the gallery (see Mobile app avatar gallery image below). The icon, name and description can be changed in the Editor Panel of the Animaze Editor.

![Animaze iOS app]({{ '/assets/images/12-843f23c0.png' | relative_url }} "Animaze iOS app"){: width="200" height="424"}   ![Animaze Editor]({{ '/assets/images/1-3c0483c8.png' | relative_url }} "Animaze Editor"){: width="1000" height="532"}

Steps to change the avatar’s **Icon**:

1. Go to the **Animaze Editor** install folder on your PC

![Go to the Animaze Editor install folder on your PC]({{ '/assets/images/2-a81575c2.png' | relative_url }} "Animaze Editor"){: width="500" height="144"}

2. Go to **Data** folder

![Go to the Animaze Editor install folder on your PC 2. Go to Data folder]({{ '/assets/images/3-834165d0.png' | relative_url }} "Animaze Editor"){: width="500" height="117"}

3. Open **Resource** folder

![Open Resource Folder]({{ '/assets/images/4-bf5a53ae.png' | relative_url }} "Animaze Editor"){: width="500" height="226"}

4. Open the avatar's folder

![Open Resource Folder 4. Open the avatar's folder]({{ '/assets/images/5-49d65eb2.png' | relative_url }} "Animaze Editor sources"){: width="500" height="139"}

5. You will find a file named **icon\\_avatarname.png,** which was automatically created by the Editor at import. By replacing/modifying this file with one of your choice, you will change the icon for the avatar in the app and Editor.

![Change the icon for the avatar in the app and Editor. ]({{ '/assets/images/6-ba4cc88f.png' | relative_url }} "Animaze Editor"){: width="500" height="203"}

*Note: **Keep the same naming convention** (icon\\_theavatarname)**, image format \\*.png (square size) in order for it to work.***

6. Animaze Editor will detect the changes made and will ask you to reimport. Click **Yes**

**![ Animaze Editor will detect the changes made and will ask you to reimport. Click Yes]({{ '/assets/images/7-c1645930.png' | relative_url }} "Animaze Editor"){: width="1000" height="533"}**

7. To see the changes, go to the **Assets** menu and select **Load Avatar**.

![To see the changes, go to the Assets menu and select Load Avatar. ]({{ '/assets/images/8-c637a7f6.png' | relative_url }} "Animaze Editor"){: width="1000" height="532"}

8. Hit the **Refresh** button, then search and select Hiyori.

![Hit the Refresh button, then search and select Hiyori.]({{ '/assets/images/9-c7572256.png' | relative_url }} "Animaze Desktop"){: width="1000" height="528"}

9. The avatar should display the new icon

![ The avatar should display the new icon]({{ '/assets/images/10-5650227e.png' | relative_url }} "Animaze Editor"){: width="1000" height="532"}

## Steps to change the Avatar’s **Name**:

1. In the **Editor Panel**, write the name you want in the **Friendly Name** field. As this name will be visible within the mobile app, we recommend that you make the name human readable (rather than random letters and numbers). That said, you can use any alphabet and special characters.

![Change the Avatar’s Name]({{ '/assets/images/11-8580e57a.png' | relative_url }} "Animaze Editor"){: width="1000" height="531"}

Steps to change the avatar’s **Description**:

1. In the **Editor Panel**, write the description you want in the **Description** field. It can be the avatar’s backstory you imagined, technical details or you can leave it blank.

![Change the avatar’s Description]({{ '/assets/images/description-1a674437.png' | relative_url }} "Animaze Editor"){: width="1000" height="531"}

**RIght click** on the avatar and select **Save item** in the **Hierarchy Panel** when you are done with the changes, be it a name, description, or other details.

![Change the avatar’s Description]({{ '/assets/images/save-fc4d4cc8.png' | relative_url }} "Animaze Editor"){: width="1000" height="529"}

If you opt for **Save item as** the Editor will create and load a copy of the current item.

i.e. when you ***Save item as*** Hiyori\\_version2, it will create a different folder in Resources directory and save it outside the original version, as a new item.

[Send the avatar to the Animaze iOS app]({{ '/manual/gettingstarted2d/sendavatar/' | relative_url }}) and see the changes, by pushing the **info button** in the upper right corner in app avatar gallery.

![Animaze ios app preview]({{ '/assets/images/12-843f23c0.png' | relative_url }} "Animaze ios app preview"){: width="200" height="424"}     ![Animaze ios app preview]({{ '/assets/images/13-426dcf24.png' | relative_url }} "Animaze ios app preview"){: width="200" height="422"}
