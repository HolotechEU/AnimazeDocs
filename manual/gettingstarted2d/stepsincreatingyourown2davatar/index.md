# Steps in creating your own 2D avatar

The purpose of this guide, is to provide the path you need to follow to create your own 2D model, using our site documentation and the external Cubism software.

Open the links of each section for better understanding the necessary steps in building an avatar and further adjust it in Animaze Editor.

The info in each link is subject to future amendments, as we further develop the Animaze apps and systems.

**Step 1**

**Cubism Editor & file formats**

On [**this link**]({{ '/manual/gettingstarted2d/createyourown/' | relative_url }} "https://www.animaze.us/manual/gettingstarted2d/createyourown") you can find the path to **install the Cubism editor**, **structure of files**, useful external **tutorial links** to get you started, explanations about the **formats** **of the files** you need to create and **tips**.

**Step 2**

**Animaze Specifics**

Read [**this overview**]({{ '/manual/technicalreference/live2davatars/' | relative_url }} "https://www.animaze.us/manual/technicalreference/live2davatars")about specifics of the Animaze systems, how they gather and operate the Live2D data, and additional data that can be configured within the Animaze Editor.

Learn about **Live2D Model Requirements & Animation Standards** [**here**]({{ '/manual/gettingstarted2d/paramlist/' | relative_url }} "https://www.animaze.us/manual/gettingstarted2d/paramlist"), also providing the **sources of a sample 2D avatar** at the end of the **Extended Parameter Set**.

**Special Actions** and **Motion Parameters** are explained [**here**]({{ '/manual/gettingstarted2d/diveinto/' | relative_url }} "https://www.animaze.us/manual/gettingstarted2d/diveinto"). If your goal is creating more complex mouth movements for your model, then check **[this part of our documentation]({{ '/manual/gettingstarted2d/complexparam/' | relative_url }} "https://www.animaze.us/manual/gettingstarted2d/complexparam")** as well.

**Step 3**

**Import the model in Animaze Editor**

When all your files are ready, start the **import process** in the Animaze Editor. Read about the steps to do that [**here**]({{ '/manual/gettingstarted2d/gettingstarted/' | relative_url }} "https://www.animaze.us/manual/gettingstarted2d/gettingstarted"). Learn to debug your model using the info on **[this link]({{ '/manual/convertavatars/convertdebugging/' | relative_url }} "https://www.animaze.us/manual/convertavatars/convertdebugging")**.

Configure the **Special Actions** and **Poses** with the help of **[this tutorial]({{ '/manual/gettingstarted2d/specialactions/' | relative_url }} "https://www.animaze.us/manual/gettingstarted2d/specialactions")**.

Walk through the process of configuring the **Leap Motion Controller,** for enriching your experience with hands-tracking [**here**]({{ '/manual/gettingstarted2d/leaplive2d/' | relative_url }} "https://www.animaze.us/manual/gettingstarted2d/leaplive2d").

**Extra**

**Idle animation**

Learn how to create a looping idle animation for a background, by reading this [**tutorial**]({{ '/manual/gettingstartedbackgrounds/loopingbackground/' | relative_url }} "https://www.animaze.us/manual/gettingstartedbackgrounds/loopingbackground").
