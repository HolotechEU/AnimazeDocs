Remap avatar animation inputs

The Animaze retargeting system expects that Live2D models have a very specific set of animation inputs. The standard is from the Cubism Editor and can be referenced in the .avatar Technical Documentation, in the Live2D avatars section.

In order to have faster iterations, the Editor does provide the means to remap the models animation inputs to align with the retargeting system standard.

1. In Editor Panel scroll down to find and expand the Live2D Options, click on the Parameter Remapping to expand it as well.

2. The left column is the expected animation input name, while the right one automatically detects and binds the correct one, as below.  

2.1. If the Live2D model doesn’t have the expected input, then “Undefined” input will display

If the input is not automatically picked-up by the Editor, most likely the input has not been created in Cubism by the artist.

2.2. The list provided for the right column drop-down is automatically detected from the Live2D model at import.

3. Once you’re done with animation input remappings, you’ll need to save the item for the changes to remain persistent.
