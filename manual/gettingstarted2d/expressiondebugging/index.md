# Expressions debugging - Avatar Puppeteering

The Avatar Puppeteering is an animation debugging tool that enables triggering the model's animation inputs without the need of the tracking capabilities that Animaze apps provide. It's role is to trigger common scenarios for face and body movements (e.g. smiles, frowns, look-at etc.).

The tool has two tabs: one for **Face And Body** and one for **Visemes****.** Here is how to use it: 

1. Open Animaze Editor and navigate to **Tools****, then select** **Avatar Puppeteering**.

![Learn how to use Animaze by Facerig]({{ '/assets/images/1-15a4cc35.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="534"}

2. **Avatar Puppeteering** opens as a floating window, which you can integrate as a panel next to the other panels, or simply keep it afloat and place it anywhere you

   want on your screen by right-clicking on it and selecting **Make Undockable**. We chose the latter, for this example.

![Learn how to use Animaze by Facerig]({{ '/assets/images/2-b4c56088.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="535"}

3. Drag the sliders to debug the expression and head animations of the avatar. Note that not all the sliders will affect it, it is relative to how the avatar was built. Clicking the **Reset** button will return the avatar to its default/neutral state.

![Learn how to use Animaze by Facerig]({{ '/assets/images/3-b8c8e1fa.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="537"}

Toggle everything you want to debug while here.

4. Now let’s test the eyes' motion accuracy. Scroll down the Avatar Puppeteering window and untick the **Eyes look at camera** option, then click & drag the point of color in the **Eyes Movement Box**; zoom in to notice the eyes’ changed position.

![Learn how to use Animaze by Facerig]({{ '/assets/images/4-eb73c5a1.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="536"}

Clicking the **Reset** button will return the avatar to its default/neutral state. 

5. In the **Visemes** tab of the Avatar Puppeteering window you can debug the visemes of the avatar using the same method. Click and drag the sliders and watch the avatar’s mouth shape changing.

![Learn how to use Animaze by Facerig]({{ '/assets/images/5-38b105ec.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="538"}

6. When you are done with debugging everything, close the window from the upper right corner.

![Learn how to use Animaze by Facerig]({{ '/assets/images/6-92e6a2e9.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="537"}

This is all. :)
