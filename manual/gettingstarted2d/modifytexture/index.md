# Quickly modify a texture on your avatar

Once you've [imported your Live2D avatar in Animaze Editor]({{ '/manual/gettingstarted2d/gettingstarted/' | relative_url }}), you can easily modify its texture directly by opening it in an image editor like Photoshop or Gimp. This is great for making quick color adjustments or in our example adding a small badge to her shirt.

For larger changes, we recommend you use the Cubism Editor. Learn more about changing materials in the Cubism Editor [here](https://docs.live2d.com/cubism-editor-manual/png-file-export-replacement/).

Here is the simplest way to modify your avatar and see the changes almost instantly:

Go to the **Animaze Editor** install folder on your PC:

1. Go to the **Animaze Editor** install folder on your PC

![Go to the Animaze Editor install folder on your PC]({{ '/assets/images/1-a81575c2.png' | relative_url }} "Animaze Editor"){: width="549" height="158"}

2. Go to **Data** folder and open the **Resources** folder

![Go to Data folder and open the Resources folder]({{ '/assets/images/2-834165d0.png' | relative_url }} "Animaze Editor"){: width="549" height="128"}

3. Open the avatar’s folder and navigate in the **Hiyori.2048** folder containing its textures (the folder is the one generated when you export the model from Cubism. Read more [here](https://sites.google.com/a/cybernoids.jp/cubism2_en/modeler/export/moc-export)).

![Open the avatar’s folder ]({{ '/assets/images/3-bf5a53ae.png' | relative_url }} "Animaze Editor"){: width="549" height="248"}   ![Open the avatar’s folder ]({{ '/assets/images/6-b0cc8552.png' | relative_url }} "Animaze Editor"){: width="549" height="179"}

4. Open the texture in the editor of your choice and draw something

![Open the avatar’s folder  4. Open the texture in the editor of your choice and draw something]({{ '/assets/images/star_texture-9578667b.png' | relative_url }} "Animaze Editor"){: width="1000" height="592"}

5. Save the texture when you are done editing, **without changing its name or location** (Animaze Editor will detect the changes automatically).

![Save the texture]({{ '/assets/images/star_text_in_folder-2d649023.png' | relative_url }} "Animaze Editor"){: width="549" height="174"}

6. Animaze Editor will detect the changes, as mentioned above, and a confirmation pop-up will prompt you to re-import the files - click **Yes.**

**![]({{ '/assets/images/7-f513f79b.png' | relative_url }}){: width="1000" height="530"}**

7. To see the changes, go to the **Assets** menu and select **Load Avatar**.

![To see the changes, go to the Assets menu and select Load Avatar]({{ '/assets/images/8-c637a7f6.png' | relative_url }} "Animaze Editor"){: width="1000" height="532"}

8. Hit the **Refresh** button, then search and select Hiyori.

![Hit the Refresh button, then search and select Hiyori.]({{ '/assets/images/9-c7572256.png' | relative_url }} "Animaze Editor"){: width="1000" height="528"}

9. The avatar should now display the modifications you made!

![Display Changes]({{ '/assets/images/10-e0b6cfd3.png' | relative_url }} "Animaze Editor"){: width="1000" height="531"}

10. **Save** the avatar in the **Hierarchy Panel** when you are done

![Save the avatar]({{ '/assets/images/save-1772ff85.png' | relative_url }} "Animaze Editor"){: width="353" height="420"}

That’s it!
