# Create an \\*.avatar bundle

Any major item type (3D/2D/Hybrid avatars, backgrounds, props) can be bundled up into a .avatar file and ready to use in Animaze apps using these simple steps. We used the 3D test avatar for exemplification.

1. Open **Animaze Editor**

2. In the **Hierarchy Panel** to the left, right click on the avatar’s name and choose **Bundle**.

![Learn how to use Animaze by Facerig]({{ '/assets/images/1-974ffdec.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="531"}

3. A new window will prompt you to save the changes, if any, made to the avatar prior to bundling it.

![Learn how to use Animaze by Facerig]({{ '/assets/images/2-215f48f1.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="532"}

4. Select the folder you want to export the bundle in. By default, the system will put it in the **Resource** directory of the Editor, but you can change this at any time. Once you decide, click **Select Folder**.

![Learn how to use Animaze by Facerig]({{ '/assets/images/3-e923b9c2.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="531"}

5. The system notifies the completion of the bundling process. Click **OK** when done.

![Learn how to use Animaze by Facerig]({{ '/assets/images/4-d99a4be5.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="532"}

As simple as that :)
