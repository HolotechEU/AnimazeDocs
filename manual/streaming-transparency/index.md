# Intro

There are a few ways of getting the Animaze rendered avatar with a transparent background and overlay or blend it into your streaming or on-demand video content. In this article, we’ll focus on three of them, with the differences being video blending quality, system resource usage (CPU & GPU), and pricing (as some options require an Animaze subscription).

Minimum software requirements:

- the latest updated version of Animaze (both Steam and Standalone versions are ok).
- for the purpose of this article, we are using **OBS 27.2.4** (downloaded from here: [Open Broadcaster Software \| OBS](https://obsproject.com/)) as video streaming or recording software.

Best results require an Animaze Subscription (Plus or Pro) unlocking the following:

- watermark removal (follow this article for more info: [Animaze FAQ \| Learn how to use Animaze by Facerig]({{ '/faq/animazedesktop/removeanimazewatermark/' | relative_url }})).
- access to Dedicated Capture Window which allows capturing the rendered frame from Animaze without the UI.
