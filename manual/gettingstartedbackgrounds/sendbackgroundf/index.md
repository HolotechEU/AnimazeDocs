# Send your background .avatar file to Animaze Avatar iOS app (on Mac, via Finder)

The \\***.avatar** file format acts like a container which can hold multiple types of avatar content, such as 3D/2D avatars, props, backgrounds.

To send your background to the app, follow the steps bellow:

1. Connect the phone to you Mac
2. Go to finder and select your phone

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/image001-8646b7ca.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="512" height="303"}

3. Once your phone is selected, select **Files**

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/image002-7a217a1a.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="512" height="315"}

4. Select **Animaze**

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/image003-3c0a0f89.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="512" height="316"}

5. **Drag and drop** your **\\*****.avatar** file from the location you have it stored in the Animaze app window and hit the **Sync** button.

![Learn how to use Animaze by Facerig \| 3D Avatars ](https://lh6.googleusercontent.com/VNYlnDw9GJTJCtPxzCL4gM-MRtjuZkesrnXOxbLfrP74oCLKBVqqwHmuafQPKdWMD0AD7G0H1faAu9DlTERt33WwDiKLtpv-QUb7DzIMzg2ihU8ibwjRZTCVttef5VFTNCHwUajr "Animaze by Facerig \| 3D Avatars "){: width="518" height="340"}

6. Restart the mobile app, you will find the new background in the Background gallery.

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/5-cbfee392.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="250" height="542"}
