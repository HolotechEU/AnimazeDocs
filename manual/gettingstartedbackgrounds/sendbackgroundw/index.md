# Send your background .avatar file to the Animaze iOS app (on Windows, via iTunes)

The .avatar file format acts like a container which can hold multiple types of avatar content, such as 3D/2D avatars, props, backgrounds.

Follow these steps:

1. Connect your device to the computer and open iTunes. You might be asked to trust your device, choose yes.
2. View your iPhone by clicking on the device's icon in the upper-left corner of the iTunes window

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/1-fbccca8c.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="650" height="473"}

3. Click on (1) **File Sharing** button in the left menu, then select (2) **Animaze** app and hit (3) **Add Folder**

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/2-aab92cd5.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="650" height="486"}

4. Select the **\\*****.avatar** file to open from the location you have it stored

![Learn how to use Animaze by Facerig \| 3D Avatars ](https://lh6.googleusercontent.com/hTyNbgFCicbQPY7lHwSUM-T_-2X_u-vDSfo-TrMr1mFsrC2DWKdgfT_hE-t4wCXgM8HdDcOy4DPkW2FkdRYKif6OOEppm4Iw_vVDz790CuzcStM0wCEpjosapkSJruCPOLf5WMPu "Animaze by Facerig \| 3D Avatars "){: width="466" height="245"}

5. The file has been added to the background gallery of the app, click **Done.**

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/3-8ea60fd9.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="650" height="432"}

6. Restart the Animaze app, and find the newly added avatar in the backgrounds gallery

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/4-cbfee392.PNG' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="250" height="542"}
