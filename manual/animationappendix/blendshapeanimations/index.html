BLENDSHAPE ANIMATIONS


BLENDSHAPE

NAME & DESCRIPTION


NaturalPose

avatar maintains a neutral expression

This blendshape is the base for all the other blendshapes.



CheekPuff_L

avatar’s left cheek inflates

Note that, when triggered with Animaze SDK, will be combined with the blended result of the following 3 extra blendshapes: Mouth_pursedLips_L, Mouth_pursedLips_Mid, Mouth_pursedLips_R


CheekPuff_R

avatar’s right cheek inflates

Note that, when triggered with Animaze SDK, will be combined with the blended result of the following 3 extra blendshapes: Mouth_pursedLips_L, Mouth_pursedLips_Mid, Mouth_pursedLips_R


MouthOpen

avatar’s mouth is open

This blendshape is built on NaturalPose & MouthOpen combined.
