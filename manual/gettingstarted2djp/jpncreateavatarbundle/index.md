# .avatarのバンドルを作成

主要なアイテムのタイプ（3D/2Dハイブリッドアバター、背景、小道具）はどれも、.avatarファイルにまとめることができ、以下の簡単なステップでAnimazeアプリ内での使用ができるようになります。具体例として3Dのテストアバターを使用します。 

1. Animazeエディターを開きます
2. 左側の階層パネルでアバターの名前を右クリックして、バンドルを選択します。

![Learn how to use Animaze by Facerig]({{ '/assets/images/1-974ffdec.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="531"}

3. バンドル化する前にアバターに変更が加えられていた場合、新しいウインドウで変更を保存するように求められます。

![Learn how to use Animaze by Facerig]({{ '/assets/images/2-215f48f1.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="532"}

4. バンドルをエクスポートしたいフォルダーを選択します。デフォルトでは、システムがエディターのリソースディレクトリをエクスポート先として指定していますが、これはいつでも変更可能です。決定したら、「フォルダーを選択」をクリックします。

![Learn how to use Animaze by Facerig]({{ '/assets/images/3-e923b9c2.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="531"}

5. システムがバンドル化プロセスの進行度と完了を通知します。終了したら、OKをクリックします。

![Learn how to use Animaze by Facerig]({{ '/assets/images/4-d99a4be5.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="532"}

こんなに簡単です。
