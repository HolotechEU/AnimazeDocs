# 表情デバッグ中 ― アバターの操作

アバターの操作は、Animazeアプリが提供するトラッキング・システム無しでモデルのアニメーションのインプットを可能にするアニメーションデバッグ中のツールです。顔と体の動きの一般的な状態（笑顔、しかめっ面、見る等）を引き起こす役目をします。

このツールには2つのタブがあります。1つは顔と体用、もう1つは口形素用です。使用方法はこちら： 

1. Animazeエディターを開き、ツールを開きます。そして、アバターの操作を選択します。

![Learn how to use Animaze by Facerig]({{ '/assets/images/1-15a4cc35.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="534"}

2. アバターの操作は、他のパネルの横にあるパネルとして統合したり、右クリックして「アンロック可能にする」を選択することでそのままスクリーン上の好きな位置に置いておいたりできる、フローティング・ウィンドウとして開きます。今回は後者を例として使用します。

![Learn how to use Animaze by Facerig]({{ '/assets/images/2-b4c56088.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="535"}

3. スライダーをドラッグして、アバターの表情と頭のアニメーションをデバッグします。全てのスライダーが作用するわけではないのでご注意ください。アバターの作成方法によって異なります。リセットボタンをクリックすると、アバターがデフォルト/無表情に戻ります。

![Learn how to use Animaze by Facerig]({{ '/assets/images/3-b8c8e1fa.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="537"}

ここでデバッグしたい物を全てトグルしてください。

4. 目の動きが正確かどうかテストしてみましょう。アバターの操作ウィンドウを下へスクロールし、カメラ目線オプションを外し、目の動きボックスの色のポイントをクリックしドラックします。目の変化した位置が分かるようにズームします。

![Learn how to use Animaze by Facerig]({{ '/assets/images/4-eb73c5a1.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="536"}

リセットボタンをクリックすると、アバターがデフォルト/無表情に戻ります。 

5. アバターの操作ウィンドウの口形素タブでは、同じ方法でアバターの口形素をデバッグできます。スライダーをクリック＆ドラッグし、アバターの口の形の変化を見てみましょう。

![Learn how to use Animaze by Facerig]({{ '/assets/images/5-38b105ec.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="538"}

6. 全てをデバッグし終えたら、右上からウィンドウを閉じてください。

![Learn how to use Animaze by Facerig]({{ '/assets/images/6-92e6a2e9.png' | relative_url }} "Animaze by Facerig"){: width="1000" height="537"}

以上です。
