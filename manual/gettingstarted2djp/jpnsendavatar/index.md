# アバターをAnimazeアバターiOSアプリに送信する方法（3つの方法）

.avatarファイルをAnimazeエディターからモバイルデバイスに送信するためには、アーティストパスのサブスクリプションが必要です。設定 \> Animazeエディター \> エディターに接続 \> 接続から、iOSモバイルアプリでアーティストパスを購入してください

アーティストパスを手に入れたら、開始準備完了です！

以下の手順に従ってください：

1. まずは、iPhoneとコンピューターが同じローカルエリアネットワーク内にあることを確認します（同じLAN/WiFi）。

2. ローカル接続を有効にする方法は2つあります：

1. Animazeエディターでツールメニューに移動して、ドロップダウンメニューからローカル接続を選択します

![Animaze Editor - Send to Animaze app]({{ '/assets/images/1-982ed3f0.png' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="1000" height="534"}

   ローカル接続

2. Animazeエディターの右上端にある「接続」ボタンをクリックして、接続します

![Animaze Editor - Send to Animaze app]({{ '/assets/images/2-80ea40dd.png' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="1000" height="532"}

3. Animazeコネクトのウィンドウが表示されます。「開始」ボタンをクリックすると、QRコードが表示されます

![Animaze Editor - Send to Animaze app]({{ '/assets/images/3-d20f32ff.png' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="1000" height="533"}

       「開始」ボタンをクリックしてQRコードを生成                               

![Animaze Editor - Send to Animaze app]({{ '/assets/images/4-4bfa76ed.png' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="1000" height="531"}

                                                                                    QRコード

4. Animaze Avatarのアプリがデバイスで開かれますので、メイン画面の右上端にある設定の歯車をクリックします

![Animaze Editor - Send to Animaze app]({{ '/assets/images/5-72a8d846.PNG' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="300" height="650"}

        Animaze Avatarのメイン画面

5. Animazeエディターまでスクロールダウンして、「接続」をクリックします

**![Animaze Editor - Send to Animaze app]({{ '/assets/images/6-33e9ffb0.PNG' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="300" height="650"}**

            アプリ内の「接続」ボタン

6. 背面カメラが開きますので、QRコードに合わせてスキャンします

**![Animaze Editor - Send to Animaze app]({{ '/assets/images/7-560bb502.PNG' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="300" height="650"}**                  

                スキャン画面

7. スマホ（左側の画像）とAnimazeエディター（右側の画像）で接続の確認が行われます

![Animaze Editor - Send to Animaze app]({{ '/assets/images/9-2e6ff957.png' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="750" height="397"}    ![Animaze Editor - Send to Animaze app]({{ '/assets/images/8-9106de44.PNG' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="200" height="433"}

    アプリとエディターにおける接続の確認

デバイスを接続したら、次の手順でアバターをモバイルデバイスに送信してください：

8. 「階層パネル」へ移動して、アバターを右クリックし、「デバイスに送信」を選択します。これにより、アバターがデバイスに送信され、\\*.avatarファイル形式でバンドル化されます。

![Animaze Editor - Send to Animaze app]({{ '/assets/images/10-88aa837e.png' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="1000" height="531"}

                                                                        アバターをデバイスに送信

9. モバイルデバイスにファイル転送の承認を求めるポップアップが表示されます

![Animaze Editor - Send to Animaze app]({{ '/assets/images/11-34bafb0a.PNG' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="300" height="650"}

                        ファイル転送のポップアップ 

10. 転送状態の承認メッセージが両方のデバイスに表示されます

**![Animaze Editor - Send to Animaze app]({{ '/assets/images/13-0ab0e89e.PNG' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="200" height="433"}     ![Animaze Editor - Send to Animaze app]({{ '/assets/images/12-302ee6b2.png' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="750" height="398"}**

    アプリとエディターにおける転送状態のメッセージ

11. アプリでアバターギャラリーを開くと、「インポートしたシェルフ」にアバターが表示されます

 **![Animaze Editor - Send to Animaze app]({{ '/assets/images/IMG_1767-acc1ea6b.PNG' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="300" height="650"}**

               アプリのアバターギャラリー

これでスマホにアバターを送信することができました 

# アバターをiOSアプリのAnimaze Avatarに送信する方法（WindowsにおいてiTunesを経由）

.avatarファイルが既に準備できている場合、以下の手順により、iTunesからiPhoneにモデルを送信することができます。まずは、設定 \> Animazeエディター \> エディターに接続 \> 接続から、iOSモバイルアプリでアーティストパスを購入してください

アーティストパスを手に入れたら、開始準備完了です！

1. デバイスをコンピューターに接続して、iTunesを開きます。デバイスを信頼するかどうか尋ねられた場合は、「はい」を選択します。
2. iTunesウィンドウの左上隅にあるデバイスのアイコンをクリックして、デバイスを表示します

![Animaze Editor - Send to Animaze app]({{ '/assets/images/14-d872ac39.png' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="750" height="521"} 

3. 左側のメニューにある「ファイル共有」のボタンをクリックして、Animazeアプリを選択し、「フォルダーを追加」を押します

![Animaze Editor - Send to Animaze app]({{ '/assets/images/15-3d1d2feb.png' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="750" height="506"}

4. .avatarファイル形式を選択して、そのファイルを保管している場所から開きます

![Animaze Editor - Send to Animaze app]({{ '/assets/images/16-08ccadeb.png' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="300" height="637"}

アバターをiOSアプリのAnimaze Avatarに送信する方法（MacにおいてFinderを経由）

.avatarファイルが既に準備できている場合、以下の手順により、 FinderからiPhoneにモデルを送信することができます。アーティストパスが必要になるため、設定 \> Animazeエディター \> エディターに接続 \> 接続から、iOSモバイルアプリでアーティストパスを購入してください

アーティストパスを手に入れたら、開始準備完了です！

1. スマホをMacに接続します
2. Finderに移動して、あなたのスマホを選択します

![Animaze Editor - Send to Animaze app]({{ '/assets/images/image039-8646b7ca.png' | relative_url }} "Animaze Editor - Send to Animaze app"){: width="512" height="303"}

3. スマホを選択したら、ファイルを選択します

**![Mac Finder - Send to Animaze app]({{ '/assets/images/image040-7a217a1a.png' | relative_url }} "Mac Finder - Send to Animaze app"){: width="512" height="315"}**

4. Animazeを選択します

**![Mac Finder - Send to Animaze app]({{ '/assets/images/image041-3c0a0f89.png' | relative_url }} "Mac Finder - Send to Animaze app"){: width="512" height="316"}**

5. .avatarファイルを保管場所からAnimazeアプリのウィンドウにドラッグ＆ドロップして、「同期」ボタンを押します

![Mac Finder - Send to Animaze app]({{ '/assets/images/image043-044f984c.jpg' | relative_url }} "Mac Finder - Send to Animaze app"){: width="620" height="382"}

6. モバイルアプリを再起動すると、サンプルアバターがアバターギャラリーに表示されています

**![Animaze app]({{ '/assets/images/16-08ccadeb.png' | relative_url }} "Animaze app"){: width="300" height="637"}**
