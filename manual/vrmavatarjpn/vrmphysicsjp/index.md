# 物理演算

# 

Animazeは.VRMモデル用にカスタマイズされた物理演算システムを実装しており、UniVRMがUnityで行うことを厳密にエミュレートしています。つまり、すべてのUniVRM物理演算機能をサポートしています。

コライダーグループ

|  |  |
| --- | --- |
| プロパティ | サポートの有無 |
| ノード | あり |
| オフセット | あり |
| 半径 | あり |

スプリングボーングループ

|  |  |
| --- | --- |
| プロパティ | サポートの有無 |
| スプリングボーンのルート | あり |
| コライダーグループ | あり |
| センター | あり |
| 抵抗力 | あり |
| 重力の方向 | あり |
| 重力の強度 | あり |
| ヒット半径 | あり |
| 剛性 | あり |
