# Animaze Virtual Camera

Use the **Animaze Virtual Camera** to appear as an avatar in video calls and on **Discord, Zoom, Skype, Meets, Teams** and the likes. You can also **stream your favourite games** as an avatar on **Twitch, YouTube, Facebook** and more using streaming software like OBS, and SLOBS.

If the old Animaze Virtual Camera driver didn’t install automatically, or if you do not know how to turn on the new Windows 11 specific Virtual webcam, check out [this FAQ]({{ '/faq/tech/virtualcameradriver/' | relative_url }}). 

Starting with Animaze version 1.27.12755 (Summer 2026), Animaze, while continuting to support is original virtual camera, has an aditional, more modern Virtual Camera solution, built specifically for Windows 11 using Windows Media Foundation Virtual Webcam Layer. Using them is similar, just that the devices are named differently in the webcam drop down, and the new one no longer requires running a driver installer, as activating it is done from within the Animaze UI itself.

Follow these steps to stream with the Animaze Virtual Camera (Animaze is compatible with all the major streaming software. For this tutorial, we used OBS as an example):

1. **Launch OBS**, set up a scene and selec**t Video Capture Device as a source**

![Animaze Virtual Camera]({{ '/assets/images/virtualcamera1-e1a477d1.png' | relative_url }} "Animaze Virtual Camera"){: width="800" height="585"}

2. Depending on which of the two you have opted to use, select either the **Animaze Virtual Camera** or **Animaze Vcam Win11 (Windows Virtual Camera)** in the **Device drop-down list**

![Animaze Virtual Camera]({{ '/assets/images/virtualcamera2-1f8fca0f.png' | relative_url }} "Animaze Virtual Camera"){: width="800" height="584"}

3. Go to **Animaze** and click on the **Enable Virtual Camera** button to **start broadcasting to OBS**.

![Animaze Virtual Camera]({{ '/assets/images/virtualcamera3-bcc524e0.png' | relative_url }} "Animaze Virtual Camera"){: width="600" height="658"}

Both **Animaze virtual cameras** are compatible with all major video conferencing platforms. For this example, we used a **Google Meets meeting.**

1. In **Google Meets**, open the **settings menu** by clicking the **three-dot button menu**.

![Animaze Virtual Camera]({{ '/assets/images/meets1-bc6c9b5d.png' | relative_url }} "Animaze Virtual Camera"){: width="800" height="508"}

2. Once you’re in the **Settings menu**, click on **Video**. Next, in the **Camera drop-down menu** select **Animaze Virtual Camera** or**Animaze Vcam Win11** **(Windows Virtual Camera)**, depending on which one you have opted to bbroadcast to in the Animaze UI.

![Animaze Virtual Camera]({{ '/assets/images/meets2-536df512.png' | relative_url }} "Animaze Virtual Camera"){: width="800" height="512"}

**![Animaze Virtual Camera]({{ '/assets/images/meets3-335eb40e.png' | relative_url }} "Animaze Virtual Camera"){: width="800" height="737"}**

3. **Go to Animaze** and click the **Enable Virtual Camera** button.

![Animaze Virtual Camera]({{ '/assets/images/meets4-d7a08596.PNG' | relative_url }} "Animaze Virtual Camera"){: width="500" height="642"}

4. Once you’ve **turned on** the **Animaze Virtual Camera** in Animaze, **you will appear as your avatar on the Google Meets** web-camera feed.

![Animaze Virtual Camera]({{ '/assets/images/meets5-510577be.PNG' | relative_url }} "Animaze Virtual Camera"){: width="800" height="526"}
