# .avatarファイルをiOSアプリのAnimaze Avatarに送信する方法（MacにおいてFinderを経由）

.avatarファイル形式は、3D/2Dアバター、小道具、背景など、複数の種類のアバターを保管するコンテナの役割を果たします。

.avatarファイルが既に準備できている場合、以下の手順により、FinderからiPhoneに送信することができます。アーティストパスが必要になるため、設定 \> Animazeエディター \> エディターに接続 \> 接続から、iOSモバイルアプリでアーティストパスを購入してください

アーティストパスを手に入れたら、開始準備完了です！

1. スマホをMacに接続します
2. Finderに移動して、あなたのスマホを選択します

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/image001-8646b7ca.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="512" height="303"}

3. スマホを選択したら、ファイルを選択します

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/image002-7a217a1a.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="512" height="315"}

4. Animazeを選択します

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/image003-3c0a0f89.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="512" height="316"}

5. .avatarファイルを保管場所からAnimazeアプリのウィンドウにドラッグ＆ドロップして、「同期」ボタンを押します

![Learn how to use Animaze by Facerig \| 3D Avatars ](https://lh3.googleusercontent.com/YXF0t3fcQxFLck3SFB9gxKgqV_YtVGdGhI8pZkUR0Sq3cTAWrXGdnENuKlJvrYfDltwrIKfm4fAN0f3Nl_g_v0kbJ-0yeklJgwaCBwYO4fBdVvEAV1ynjMlybHwUgHZ7mCD_f7lf "Animaze by Facerig \| 3D Avatars "){: width="507" height="333"}

6. モバイルアプリを再起動すると、サンプルアバターがアバターギャラリーに表示されています

![Learn how to use Animaze by Facerig \| 3D Avatars ](https://lh6.googleusercontent.com/0OljkzzR5NwWBZsKTi-6bZ508FReL1WzKwv7gV7waCO7rNwFA3L44H9WHLrFvkb-5-pdralHTvilMWXBo2klfSGHeQoHqKvkAMYx4S3vhutka-AQ9M5wIdCAU9xqFyffuyspjCau " Animaze by Facerig \| 3D Avatars "){: width="188" height="406"}
