# 小道具の.avatarファイルをiOSアプリのAnimaze Avatarに送信する方法（MacにおいてFinderを経由）

.avatarファイル形式は、3D/2Dアバター、小道具、背景など、複数の種類のアバターを保管するコンテナの役割を果たします。

.avatarファイルが既に準備できている場合、以下の手順により、FinderからiPhoneに送信することができます。アーティストパスが必要になるため、設定 \> Animazeエディター \> エディターに接続 \> 接続から、iOSモバイルアプリでアーティストパスを購入してください

アーティストパスを手に入れたら、開始準備完了です！

1. スマホをMacに接続します
2. Finderに移動して、あなたのスマホを選択します

![About Animaze by Facerig \| Send props]({{ '/assets/images/image001-8646b7ca.png' | relative_url }} "About Animaze by Facerig \| Send props"){: width="512" height="303"}

3. スマホを選択したら、ファイルを選択します

![About Animaze by Facerig \| Send props]({{ '/assets/images/image002-7a217a1a.png' | relative_url }} "About Animaze by Facerig \| Send props"){: width="512" height="315"}

4. Animazeを選択します

![About Animaze by Facerig \| Send props]({{ '/assets/images/image003-3c0a0f89.png' | relative_url }} "About Animaze by Facerig \| Send props"){: width="512" height="316"}

5. .avatarファイルを保管場所からAnimazeアプリのウィンドウにドラッグ＆ドロップして、「同期」ボタンを押します

![About Animaze by Facerig \| Send props]({{ '/assets/images/image004-beee7d64.png' | relative_url }} "About Animaze by Facerig \| Send props"){: width="512" height="337"}

6. Animazeアプリを再起動してアバターギャラリーを開き、カスタマイズするアバターを選択します

![About Animaze by Facerig \| Send props]({{ '/assets/images/image006-8edf13ae.png' | relative_url }} "About Animaze by Facerig \| Send props"){: width="250" height="541"}

7. カスタマイズ画面の帽子オプションで、スマホへ送信した小道具を見つけます

![About Animaze by Facerig \| Send props]({{ '/assets/images/image008-2be085c3.png' | relative_url }} "About Animaze by Facerig \| Send props"){: width="250" height="542"}

8. その小道具を選択し、必要に応じてスライダーを左右にドラッグしてサイズを調整し、アバターの頭に合わせます。合わせ終わったら緑色のチェックマークをクリックします

![About Animaze by Facerig \| Send props]({{ '/assets/images/image010-16149086.png' | relative_url }} "About Animaze by Facerig \| Send props"){: width="250" height="541"}

9. 保存するスロットを選択します

![About Animaze by Facerig \| Send props]({{ '/assets/images/image012-21f254ff.png' | relative_url }} "About Animaze by Facerig \| Send props"){: width="250" height="541"}

10. メイン画面に王冠をかぶったアバターが表示されます

![About Animaze by Facerig \| Send props]({{ '/assets/images/image014-a2b44a3d.jpg' | relative_url }} "About Animaze by Facerig \| Send props"){: width="250" height="541"}

面白い動画や画像の制作をお楽しみください！
