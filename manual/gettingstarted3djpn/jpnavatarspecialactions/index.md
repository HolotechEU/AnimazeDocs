# アバターの特殊アクションを設定する方法

[特殊アクション]({{ '/manual/gettingstarted2d/diveinto/' | relative_url }})は、ユーザーが実行させるアニメーションであり、顔のトラッキングのリターゲティングシステムの一部ではありません。特殊アクションとしては、アバターに表示させたいかっこいいダンスの動きなどを想像してください。

特殊アクションの可能性は無限大ですが、「特殊アクションのアニメーションは階層内の全ボーンにエクスポートしなければならない」というルールは守る必要があります。

他のアニメーションと同様、\\*.fbxという形式であり、Animazeエディター内で追加したり、調整したり、削除したりできます。 

特殊アクションを設定する手順：

1. Animazeエディターを開きます

エディターパネルで「特殊アクション」バーをクリックし、展開させます

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/step2-bf5a85fa.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="426"}

3. 「特殊アクションを設定」ボタンをクリックすると、設定ウィンドウが開きます

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/step3-a526df66.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="427"}

4. 「アクションを追加」ボタンをクリックし、.fbxファイルを含むソースフォルダーから特殊アクションのアニメーションを選択して、「開く」を押します。

   ソースフォルダーの場所と名前は保存場所とフォルダーに付けた名前により異なりますので、ご注意ください。フォルダーのデフォルト名は「AvatarFrogTest」です。

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/step4-b77b3cf1.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="426"}

5. OKをクリックしてアニメーションの追加を終えます。

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/step5-5d0945a7.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="428"}

6. 「実行」ボタンをクリックして、アニメーションを実行させ、アバターがアクションを実行するのを確認します

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/step6-7ef91a6d.png' | relative_url }} "Learn how to use "){: width="800" height="428"}

7. 作業を終えたら、階層パネルでアバターを保存します

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/step7-c618e50a.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="348" height="429"}

これで特殊アクションを設定できました
