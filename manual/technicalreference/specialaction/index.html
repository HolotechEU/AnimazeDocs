Special Actions

Special Actions are pre-existing animations that can be played by the avatar when the user is triggering it via a keypress or a UI button tap. These special animations do not override the tracking inputs coming from any tracking technology, therefore they can be built for the body, while the avatar’s face will display the tracked motions coming from you.

Special Actions need to have all the bones in the skeletal hierarchy animated, as when activated, they replace the idle1 animation. We use 4 standard Special Actions, namely:

  1. Hello – hand wave salute

  2. No – wagging finger in a refusing gesture

  3. Ok – thumbs up

  4. I don’t know – shrug
