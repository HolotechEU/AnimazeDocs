# UV Mapping

# 

The model should have normalized mapping in 0-1 UV space. Create unique mapped models (with no overlapping for Fur and Skin (SSS) materials), because there are material types that need this kind of mapping. All polygons must have mapping coordinates. These rules also apply  for  the mobile platform.
