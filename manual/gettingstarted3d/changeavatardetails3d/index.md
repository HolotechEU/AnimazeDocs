# Change the avatar details (icon, description & name)

An avatar’s details can be viewed in the iOS app, by tapping the Info button that appears in the top right corner when your avatar is previewed in the gallery (see Mobile app avatar gallery image below). The icon, name and description can be changed in the Editor

   ![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/01-f90cd4ae.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="250" height="541"}        ![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/001-67cdf8d7.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="250" height="542"}

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/1-79b72a75.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="425"}

Animaze automatically creates an icon for the imported item. However, you might want to change that with an image that represents the avatar better. Below we detail where you find the avatar’s icon, how to change it and how to view your results in the Animaze app. 

### Steps to change your Avatar’s icon:

1. Go to the Animaze Editor install folder on your PC

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/2-c2b63c84.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="463" height="111"}

2. Go to **Data** folder

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/3-944ac3b4.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="465" height="130"}                                        

3. Open **Resources** folder

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/4-efa72c2a.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="464" height="193"}

4. Open the avatar’s folder

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/5-9194355a.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="522" height="197"}

5. You will find a file named **icon\\_AvatarName.png**, which was automatically created by the Editor at import. Create a new icon image for it, with a square size and naming convention icon\\_AvatarName. This way you will change the icon for the avatar in the app and Editor.

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/6-5ad43d8e.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="520" height="263"}

                      

You must keep the same naming convention (**icon\\_*AvatarName***), image format **\\*.png** and a **square size** in order for it to work.

6. Animaze Editor will detect the changes made and will ask you to reimport. Click **Yes**

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/7-8b76ebf2.png' | relative_url }} " Animaze by Facerig \| 3D Avatars "){: width="800" height="423"}

                                              

7. To see the changes, go to the **Assets** menu and select **Load Avatar****.**

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/8-d656aa62.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="426"}

8. Hit the **Refresh** button, then search and select AvatarFrogTest avatar

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/9-23590b40.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="426"}

      9.  The avatar should display the new icon

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/10-d46c0f92.png' | relative_url }} " Animaze by Facerig \| 3D Avatars "){: width="800" height="423"}

### Steps to change your Avatar’s name:

1. Open Animaze Editor
2. In the **Editor Panel**, write the desired name in the **Friendly Name** field. We recommend that you make the name human readable (rather than random letters and numbers). That said, you can use any alphabet and special characters.

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/11-b45a65d3.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="426"}

### Steps to change your Avatar’s description:

1. Open Animaze Editor
2. In the **Editor Panel**, write the desired description in the **Description** field. It can be the avatar’s backstory you imagined, technical details or you can leave it blank.

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/12-89ffe4ed.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="427"}

3. **Save item** in the **Hierarchy Panel** when you are done with the changes, be it name, description or other details.  If you exit the Animaze Editor without saving, all of your work will be lost.

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/13-9911d0c5.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="357" height="487"}

If you opt for **Save item as**, the Editor will create and load the new saved version of the item.

i.e. when you **Save item** **as** "FrogAvatar", it will create a different folder in Resources directory and save it outside the original version, as a new item. 

Go to the Avatar gallery in the iOS app and find the avatar after you’ve sent it to your device. Tap the Info button and see the description you added.
