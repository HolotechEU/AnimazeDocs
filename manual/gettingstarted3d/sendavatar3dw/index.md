# Send your .avatar file to the Animaze iOS app (on Windows, via iTunes)

The **\\*****.avatar** file format acts like a container that can hold multiple types of avatar content, such as 3D/2D avatars, props, backgrounds.

If you have your .avatar file already prepared, you can send it to your iPhone through iTunes, by following the steps below.

Editor, by following these steps:

1. Connect your device to the computer and open iTunes. You might be asked to trust your device, choose yes.
2. View your iPhone by clicking on the device's icon in the upper-left corner of the iTunes window

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/1l-fbccca8c.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="600" height="437"}

3. Click on (1) **File Sharing** button in the left menu, then select (2) **Animaze** **app** and hit (3) **Add Folder.**

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/2l-aab92cd5.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="598"}

4. Select the **\\*.avatar** file to open from the location you have it stored

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/4l-5541dcaa.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="500" height="234"}

5. The file has been added to the avatar gallery, click **Done.**

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/3l-8ea60fd9.png' | relative_url }} " Animaze by Facerig \| 3D Avatars "){: width="800" height="531"}

6. Restart the Animaze app, and find the newly added avatar in the gallery

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/5l-cd02c6e5.png' | relative_url }} " Animaze by Facerig \| 3D Avatars "){: width="250" height="542"}
