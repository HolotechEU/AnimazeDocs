# Physics

Animaze implements a custom tailored physics system for .VRM models that emulates closely what UniVRM does in Unity, which means it supports all UniVRM physics features.

Collider groups

|  |  |
| --- | --- |
| Property | Supported |
| Node | Yes |
| Offset | Yes |
| Radius | Yes |

### Spring bone groups

|  |  |
| --- | --- |
| Property | Supported |
| Root of spring bone | Yes |
| Colliders groups | Yes |
| Center | Yes |
| Drag force | Yes |
| Gravity direction | Yes |
| Gravity power | Yes |
| Hit radius | Yes |
| Stiffness | Yes |
