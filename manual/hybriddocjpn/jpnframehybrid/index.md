# アバターにフレームをつける方法

カメラ設定を行うことで、アプリにおけるアバターの表示方法をコントロールすることができます。アバターに完璧なフレームをつけるために気にしすぎる必要はありません。ピンチでズームイン/アウトすることで、アプリ内でアバターのフレームを調整することができます。

方法はこちら：

1. Animazeエディターを開きます

右側のエディターパネルでスクロールダウンし、「アイテムカメラ設定」バーをクリックして開きます

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/step2-462c810e.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="427"}

3. FollowCameraの視野を変更すると、カメラビューアングルの広さを設定することができます。視野を30（1）に設定し、アスペクト比デバッガーを使ってiOSアプリでの表示をプレビューすることで、モバイル画面での表示を確認することができます。「表示」（2）へ移動し、「アスペクト比」（3）選択し、そこに表示されているアスペクト比のうちの1つを選択します。

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/step3-3cd3fe5c.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="427"}

4. アスペクト比が9:16のスマホにはこのように表示されます。結果に問題がなければ、階層パネルでアイテムを保存します。

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/step4-8f1b76be.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="425"}

5. 階層パネルでアイテムを保存して、次回以降にアバターを読み込んだときに設定を保持できるようにします

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/step5-c618e50a.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="348" height="429"}
