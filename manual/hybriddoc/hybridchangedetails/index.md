# Change the avatar details (icon, description & name)

An avatar’s details can be viewed in the iOS app by tapping the **Info** button that appears in the top right corner when your avatar is previewed in the gallery (see Mobile app avatar gallery image below). The icon, name and description can be changed in the Animaze Editor.

Animaze automatically creates an icon for the imported item. However, you might want to change that with an image that represents the avatar better. Below we detail where you find the avatar’s icon, how to change it and how to view your results in the Animaze mobile app.

### Steps to change your Avatar’s icon:

1. Go to the Animaze Editor install folder on your PC

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/7a-c2e40def.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="450" height="127"}

2. Go to **Data**folder

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/8a-4e9bdbb7.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="450" height="104"}

3. Open **Resources**folder

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/9a-dd3451f4.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="450" height="236"}

4. Open the avatar’s folder

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/10a-11ad2ab8.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="450" height="176"}

5. You will find a file named **icon\\_AvatarName.png**, which was automatically created by the Editor at import. Create a new icon image for it, with a square size and naming convention**icon\\_AvatarName**. This way you will change the icon for the avatar in the app and Editor.

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/11a-b77e5768.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="450" height="191"}

You must keep the same naming convention (**icon\\_AvatarName**), image format **\\*.png** and a square size in order for it to work.

6. Animaze Editor will detect the changes made and will ask you to reimport. Click **Yes.**

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/12aa-ee7c1791.png' | relative_url }} " Animaze by Facerig \| 3D Avatars "){: width="800" height="425"}

7. To see the changes, go to the **Assets**menu and select **Load Avatar**.

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/12a-d0524cd1.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="429"}

8. Hit the **Refresh**button, then search and select avatar.

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/13a-79742bfb.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="424"}

      9.  The avatar should display the new icon.

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/14a-90acecf5.png' | relative_url }} " Animaze by Facerig \| 3D Avatars "){: width="800" height="425"}

### Steps to change your Avatar’s name:

1. Open Animaze Editor
2. In the **Editor Panel**, write the desired name in the **Friendly Name** field. We recommend that you make the name human readable (rather than random letters and numbers). That said, you can use any alphabet and special characters.

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/15a-b176e36b.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="428"}

### Steps to change your Avatar’s description:

1. Open Animaze Editor
2. In the **Editor Panel**, write the desired description in the **Description**field. It can be the avatar’s backstory you imagined, technical details or you can leave it blank.

![Learn how to use Animaze by Facerig \| 3D Avatars]({{ '/assets/images/16a-830104f2.png' | relative_url }} "Animaze by Facerig \| 3D Avatars"){: width="800" height="427"}

3. **Save item** in the **Hierarchy Panel** when you are done with the changes, be it name, description or other details.  If you exit the Animaze Editor without saving, all of your work will be lost.

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/save-381c3287.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="300" height="395"}

i.e. when you **Save item as****...** under another name, it will create a different folder in **Resources**directory and save it outside the original version, as a new item.

Go to the Avatar gallery in the app and find the avatar after you’ve [sent it to your device]({{ '/manual/hybriddoc/hybridiositunes/' | relative_url }} "Send your hybrid avatar to the Animaze iOS app (on Windows, via iTunes)"). Tap the **Info**button and see the description you added.
