# How to frame the avatar

You can control how the avatar is displayed in the Animaze apps by configuring the camera settings within the Editor. Don’t worry too much about framing your avatar perfectly. You can refine how the avatar is displayed in the app by pinching to zoom in and out.

Here is how to do it in Animaze Editor:

1. Open Animaze Editor
2. In the **Editor Panel** to the right, scroll down and click to expand the **Item Camera Settings** bar.

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/1r-704c9dfa.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="427"}

3. You can set the wideness of the camera view angle, by changing the values for **Field of View** on **FollowCamera**. We set the **FoV** to 25 (1) and we can preview it as in the iOS app by using the **Aspect Ratio debugger**, to see how it will look like on a mobile screen. Go to **View**, select **Aspect Ratio** (2) and pick one of the aspect ratios listed there (3).

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/2r-269243e4.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="428"}

4. This is how it would look on a mobile phone with a screen aspect ratio of 9:16. If you’re happy with the result, save the item in the **Hierarchy Panel** in the next step.

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/3r-b4b5bd0e.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="425"}

5. **Save** the item in the **Hierarchy Panel** to keep the settings for next time you load the avatar.

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/4r-381c3287.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="300" height="395"}
