# Send your hybrid avatar to the Animaze iOS app (on Windows, via iTunes)

The .avatar file format acts like a container that can hold multiple types of avatar content, such as 3D/2D/hybrid/.VRM avatars, props, backgrounds.

If you have your .avatar file already prepared, you can send it to your iPhone through iTunes, by following the steps below.

Editor, by following these steps:

1. Connect your device to the computer and open iTunes. You might be asked to trust your device, choose yes.
2. View your iPhone by clicking on the device's icon in the upper-left corner of the iTunes window

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/image001-93267747.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="669" height="487"}

3. Click on (1) File Sharing button in the left menu, then select (2) Animaze app and hit (3) Add Folder

![Learn how to use Animaze by Facerig \| 3D Avatars ]({{ '/assets/images/image003-5b43c877.png' | relative_url }} "Animaze by Facerig \| 3D Avatars "){: width="800" height="598"}

4. Select the .avatar file to open from the location you have it stored

![Learn how to use Animaze by Facerig \| 3D Avatars ](https://lh5.googleusercontent.com/OxHPVKjqB3dN4YBJufwGoeg9pJnXJ-v6d3Rf0lyJ_l3G_OeGZsSFozeuhXWHyemEApBOHtnzE7bI4Y88jru_SJ19FC2QMeXurJ7e-qOKGy2Vbp687S3ixsANTNHDcfRrGIguOOdP "Animaze by Facerig \| 3D Avatars "){: width="535" height="250"}

5. The file has been added to the avatar gallery, click Done.

![Learn how to use Animaze by Facerig \| 3D Avatars ](https://lh6.googleusercontent.com/ZSGzY-T5aNxqGEslKrQgBK1iiUg0CwGr5Bj4PWwk39W62YkKqKmxFLmdq-Lj0Ra7gxN1N3MGTTjlLnu1fNl97A_vy1suCPS5YRRxUr9ebmnu079VpJ9jwBCjFP4v3L6BmNhQ6lNM " Animaze by Facerig \| 3D Avatars "){: width="624" height="415"}

6. Restart the Animaze app, and find the newly added avatar in the gallery

![Learn how to use Animaze by Facerig \| 3D Avatars ](https://lh6.googleusercontent.com/0OljkzzR5NwWBZsKTi-6bZ508FReL1WzKwv7gV7waCO7rNwFA3L44H9WHLrFvkb-5-pdralHTvilMWXBo2klfSGHeQoHqKvkAMYx4S3vhutka-AQ9M5wIdCAU9xqFyffuyspjCau " Animaze by Facerig \| 3D Avatars "){: width="188" height="406"}
