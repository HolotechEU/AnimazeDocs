# Animaze iPhone: What to do if I have an issue that is not in the FAQ?

![]({{ '/assets/images/new-issue_GIF-577f5bec.gif' | relative_url }}){: width="240" height="520"}

1. If an issue is not found in the FAQ section, please report it to us.

2. Tap on the![](https://lh3.googleusercontent.com/1JGIg3SAYiHYY52VxANsN3i-eSIohmgxCvJTtNB7cAxBrCcI8j-NucqfzZZtcFSAj5eunAs9_SF_7fYE2TDEto8JpYfIWRSDUHcNycqocB15ufWwCKvZpMI8h0PjfHQXXGPfXo-y){: width="32" height="32"} menu.

3. Tap on Support.

4. Write a subject and detail the issue in the body of the email.

1. For faster resolution, consider including your User ID. Your user ID can be copied from the Settings menu.

5. Tap on Send.

NOTE: If you want to delete the message and return to the previous menu, tap on Cancel and then on Delete Draft.
