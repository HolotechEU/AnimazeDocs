# Animaze iPhone: How do I customize avatars? (shape and color)

![]({{ '/assets/images/avatarcustomization_GIF-2ce86f56.gif' | relative_url }}){: width="240" height="520"}

1. Tap on the Avatars icon ![]({{ '/assets/images/T_FX1VJJQ4Pt9hau8oh1RDnEL1vhQu7Cnaq2GwtHC2iooI230FdsOustazyIC5sC446NTBLYqkDq1hQE5zWM77LUwq0rdICdAaQ-upOp3ivPVmAkRHO2tUsBs9IdrvzSuxpWEgpF-96ef299d.png' | relative_url }}){: width="35" height="35"} and select the avatar you want to customize

2. Tap on the paintbrush icon ![]({{ '/assets/images/v7bRHY6lDoQbcOsAsRbGpVhaUIlto5QMa4L2cWV2nM8hNq0nDn2vWUtuPeaFWU9A1gpDEDc3wmzHPTH6OKhiOWW_YpmWjrwvIqbRIU7tDRPL_SD5Pulb2-oBVhs48lfPU6cE80fg-0d65044e.png' | relative_url }}){: width="36" height="36"}. The Customization screen will appear.

3. Select body parts using the drop-down list.

- Change the size of body parts using sliders. Reduce the size, height or width by sliding to the left. Increase size, height or width by sliding to the right The new size will be previewed in real time.
- Change the color of body parts by  selecting a color in the menu next to the body part you would like to change. . The new color will be previewed in real time.

**PRO TIP:** To select a color that is not in the color menu, click on the color selector icon  ![]({{ '/assets/images/Rm2YrFEZ48RDbMUq3fr_vVDf0OEsLFLsnQXLWfTnhsp0Ipmug6nFpJEpia2Sp_CHdS1uGqFV7Wvgo0v330WuaIG1RfzXRgO_j_i8wvi4NpQ7cfYdC5KJAxNwckNoS45EXsUA4GWI-e82e2d28.png' | relative_url }}){: width="30" height="28"}.

5. Tap on the green checkmark ![]({{ '/assets/images/3LjquyWG-S6eD_czJgsun5-1N-mj1JoCvzvbh-wcWysMoaEKwH6svYq5YNvT3xHbOwQDt_m0enVXrGGF84I0LZoyWUMEBLQ4nCWBa1T04IbADQNGb682Bwfbsm_XmIiuoRFU5zUY-0402e192.png' | relative_url }}){: width="34" height="31"} to save the customized avatar.
