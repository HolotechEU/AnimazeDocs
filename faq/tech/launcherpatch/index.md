# Animaze Launcher: Update patch 1.26.12623

This affects all users running Animaze Launcher versions below 1.26.12623.

Due to security concerns, previous versions of Animaze Launcher are no longer compatible with auto updater. You can check your Animaze Launcher version in its title bar. If you find your Animaze Launcher version to be below the aforementioned version, please manually patch your app in order to receive future updates.

---

## Method 1: Launcher Patcher

1. Make sure AnimazeLauncher.exe is not currently running
2. Download the Animaze Launcher patcher provided [here](https://s3.amazonaws.com/animaze.us/AnimazeLauncherPatcher_1_26_12623.zip)
3. Unzip to a known location
4. Run AnimazeLauncherPatcher\\_1\\_26\\_12623 with admin privileges and Click Next
5. The patcher automatically detects where your current Launcher is already installed and automatically fill in the Destination Folder. Make sure the Destination Folder is correct, containing the Animaze Launcher installation, or change it manually.
6. Click Install, you should see the 'Patching completed successfully' message
7. Run AnimazeLauncher.exe and confirm your current version is now 1.26.12623

---

## Method 2: Manually copy the Patch files

The above method is preffered, however, there are instances where some Windows installations may block the execution for the patcher. In this case, we have provided the patched files, in plain, which can be coppied manually.

1. Make sure AnimazeLauncher.exe is not currently running
2. Download the Animaze Launcher patcher provided [here](https://s3.amazonaws.com/animaze.us/AnimazeLauncherPatcher_1_26_12623.zip)
3. Unzip to a known location
4. Locate your current AnimazeLauncher install directory.
5. From the unzipped location, manually copy and overwrite AnimazeLauncher.exe in to AnimazeLauncher/bin/AnimazeLauncher.exe
6. From the unzipped location, manually copy and overwrite AnimazeLauncher.exe in to AnimazeLauncher/data/AnimazeLauncher.avatar
7. Run AnimazeLauncher.exe and confirm your current version is now 1.26.12623
