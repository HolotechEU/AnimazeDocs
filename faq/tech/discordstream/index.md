# Animaze Desktop: How do I video chat/stream on Discord?

First of all, **install the Discord app** [from their official website](https://discord.com/download) and open the app! Please note that the Animaze app only works with the **Discord Windows app** at the moment!

Go to **User Settings**

![Animaze FAQ \| Learn how to use Animaze by Facerig]({{ '/assets/images/image_18__1-4573601d.png' | relative_url }} "Animaze FAQ \| Learn how to use Animaze by Facerig"){: width="800" height="448"}

Navigate towards the **Voice and Video Tab** and from the **Video Settings Category select Animaze Virtual Webcam**

![Animaze FAQ \| Learn how to use Animaze by Facerig]({{ '/assets/images/image_19_-80948d90.png' | relative_url }} "Animaze FAQ \| Learn how to use Animaze by Facerig"){: width="800" height="607"}

![Animaze FAQ \| Learn how to use Animaze by Facerig]({{ '/assets/images/image_21_-9fac413b.png' | relative_url }} "Animaze FAQ \| Learn how to use Animaze by Facerig"){: width="800" height="481"}

Go back to Animaze and click the '**Connect to Stream**' button
