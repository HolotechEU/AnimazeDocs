# Animaze Desktop: How can I use the Twitch integration?

With Animaze’s Twitch integration, program your avatar to react with an emote or animation, change your scene, or use a voice effect when people type a specific word in the chat, subscribe, gift subs, or when you’re hosting or raiding.

Click on the **Quick Scenes icon** to open the **Stream Actions drawer men****u**

Click on **Twitch Actions**

![Animaze FAQ \| Learn how to use Animaze by Facerig]({{ '/assets/images/twitchactions1-4386277c.png' | relative_url }} "Animaze FAQ \| Learn how to use Animaze by Facerig"){: width="734" height="746"}

Type the name of your **Twitch channel in the “Twitch channel” field**. Just enter your channel name. We’ve written [www.twitch.tv](http://www.twitch.tv) for you. Use the toggle below the channel field to connect to your Twitch channel and stream.

![Animaze FAQ \| Learn how to use Animaze by Facerig]({{ '/assets/images/twitchactions2-7c45725d.png' | relative_url }} "Animaze FAQ \| Learn how to use Animaze by Facerig"){: width="735" height="744"}

Click on the “**Create a twitch action**” button to start creating an action.

**![Animaze FAQ \| Learn how to use Animaze by Facerig]({{ '/assets/images/twitchactions3-cd6cfbd6.png' | relative_url }} "Animaze FAQ \| Learn how to use Animaze by Facerig"){: width="738" height="745"}**

**Click on the arrow to show the drop-down list of options** and **choose an option to trigger the avatar’s action**: A word said in the chat, Subs, Gift Subs, Host, or Raid.   
For this FAQ, we chose **A word is said in the chat.**

![Animaze FAQ \| Learn how to use Animaze by Facerig]({{ '/assets/images/twitchactions4-2638b22f.png' | relative_url }} "Animaze FAQ \| Learn how to use Animaze by Facerig"){: width="733" height="744"}

Type the desired **word** in the field below. When the Match word case toggle is ON, the word is case sensitive; when it is OFF, the word is no longer case sensitive

       If desired, **set a cooldown timer (in seconds) for triggering the action**. For example, entering the number 5 means that the avatar will not respond for five seconds even if the triggering event occurs. 

![Animaze FAQ \| Learn how to use Animaze by Facerig]({{ '/assets/images/twitchactions5-17df8b9d.png' | relative_url }} "Animaze FAQ \| Learn how to use Animaze by Facerig"){: width="740" height="746"}

Click on **Next**, and choose what the avatar will do when the word appears in the chat. **Quick Scene** (changes the quick scene), **Voice** (applies a voice effect), Emote (plays an emote), **Animation** (plays the applicable animation). 

For this FAQ, we chose an **Emote**

![Animaze FAQ \| Learn how to use Animaze by Facerig]({{ '/assets/images/twitchactions6-4dace3d5.png' | relative_url }} "Animaze FAQ \| Learn how to use Animaze by Facerig"){: width="737" height="745"}

Select the **Emote** that you want to trigger and click on **Save in the Emotes drawer menu.**

![Animaze FAQ \| Learn how to use Animaze by Facerig]({{ '/assets/images/twitchactions7-40724c86.png' | relative_url }} "Animaze FAQ \| Learn how to use Animaze by Facerig"){: width="738" height="746"}

Click on **Next** after you’ve chosen your desired emote.

![Animaze FAQ \| Learn how to use Animaze by Facerig]({{ '/assets/images/twitchactions8-75cdeb63.png' | relative_url }} "Animaze FAQ \| Learn how to use Animaze by Facerig"){: width="735" height="744"}

Click **Play** to preview the action that you set up. Click **Save** to save the action that you created.

![Animaze FAQ \| Learn how to use Animaze by Facerig]({{ '/assets/images/twitchactions9-4e4ede9c.png' | relative_url }} "Animaze FAQ \| Learn how to use Animaze by Facerig"){: width="736" height="745"}
