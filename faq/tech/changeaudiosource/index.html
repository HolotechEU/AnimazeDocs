Animaze Desktop: How can I change the audio input source?

After you install Animaze and its Virtual Microphone driver (check out how here), this driver may become the default input source for Windows. Here is how to change the source back: 

1. Go to Sound Settings in Windows (press Windows key and type “Sound Settings”)

2. Use the drop-down list under “Output” to select your output speakers

3. Use the drop-down list under “Input” to select your input source (actual microphone)
