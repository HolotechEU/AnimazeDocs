# Animaze Desktop: How can I install the Animaze Virtual Microphone?

In order to **install the Animaze Virtual Microphone**, **keep the Animaze app closed throughout the entire process**. If Animaze is open during the installation process it will not automatically pick up the mic and you will need to restart the application once the mic is installed.

1. Install Animaze from **[Steam](https://store.steampowered.com/app/1364390/Animaze_by_FaceRig/)**
2. Go to the **Animaze bin folder in the Steam folder**. You can do so by **clicking Animaze Settings in Steam -\> Manage-\> Browse Local files**

![How can I install the Animaze Virtual Microphone]({{ '/assets/images/01-bc247905.png' | relative_url }} "How can I install the Animaze Virtual Microphone"){: width="568" height="405"}

3. From the **Bin folder,** access the **Prerequisites folder** and **open AnimazeVirtualMicrophone**

![How can I install the Animaze Virtual Microphone]({{ '/assets/images/02-6f5f6b4d.png' | relative_url }} "How can I install the Animaze Virtual Microphone"){: width="737" height="187"}

4. Select to **run the install.bat file**

**![How can I install the Animaze Virtual Microphone]({{ '/assets/images/03-9bb23f61.png' | relative_url }} "How can I install the Animaze Virtual Microphone"){: width="800" height="260"}**

5. **Once the microphone is installed**, Animaze Virtual Mic will take control of your audio setup (both output and input, to change this see [this FAQ]({{ '/faq/animazedesktop/changeaudiosource/' | relative_url }}))

Please note: When you are using the broadcasting function, you need to select the Animaze Virtual Mic in the program settings through which you are broadcasting (e.g., OBS or Zoom)
