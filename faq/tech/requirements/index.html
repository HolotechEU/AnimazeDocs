Animaze Desktop: What are the minimum requirements for PCs to stream with Animaze?

The answer to this question highly depends on the game you are streaming along or the streaming scenario

Streaming React Content or Just Chatting

This scenario should work with the basic usage recommended specs.

RECOMMENDED
Processor Intel® Core™ i5 6th generation ~3.3 GHz or equivalent
Memory 8 GB RAM
Graphics NVIDIA GeForce GTX 980 or equivalent

Streaming fairly optimized or indie games

Indie games that either are fairly optimize (e.g. League of Legends, CS:GO, Valorant, etc.) or don't require lots of resources (e.g. Stardew Valley, Celeste, Disco Elysium, Cuphead, etc.) should run along Animaze and OBS (or video encoding and streaming) on a mid-range PC.

RECOMMENDED
Processor Intel® Core™ i5 7th generation ~3.3 GHz or equivalent
Memory 16 GB RAM
Graphics NVIDIA GeForce GTX 1060 or equivalent

Streaming CPU/GPU intensive games

AAA games that utilize the system resources to their full (e.g. Apex Legends, Marvel’s Spider-Man Remastered, God of War, etc.) require high specs.

It is recommended to have a two PC setup, with one PC dedicated to Animaze and OBS (or video encoding and streaming), while the second one dedicated to the game being streamed.

RECOMMENDED
Processor Intel® Core™ i7 10th generation ~4.1 GHz or equivalent
Memory 32 GB RAM
Graphics NVIDIA GeForce RTX 2060 or equivalent
