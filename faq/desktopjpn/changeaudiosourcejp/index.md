# 音声入力のソースを変更するにはどうすればよいですか？

AnimazeとVirtual Microphoneドライバーをインストールすると、このドライバーがWindowsのデフォルトの入力ソースとなる場合があります。次の手順で入力ソースを元の設定に戻します:

1.Windowsのサウンドの設定を開きます(Windowsキーを押し、「サウンドの設定」と入力します)

![Learn how to change the audio input source in Animaze by Facerig through this simple tutorial ]({{ '/assets/images/01_1-b3bb16ba.png' | relative_url }} "Learn how to change the audio input source in Animaze by Facerig through this simple tutorial "){: width="814" height="783"}

2.「出力」の項目にあるドロップダウンメニューからお使いのスピーカーを選択します

![Learn how to change the audio input source in Animaze by Facerig through this simple tutorial ]({{ '/assets/images/02_1-8a6457b2.png' | relative_url }} "Learn how to change the audio input source in Animaze by Facerig through this simple tutorial "){: width="814" height="783"}

3.「入力」の項目にあるドロップダウンメニューからお使いの入力ソース(実際に使用するマイク)を選択します

![Learn how to change the audio input source in Animaze by Facerig through this simple tutorial ]({{ '/assets/images/03_1-092ffbf2.png' | relative_url }} "Learn how to change the audio input source in Animaze by Facerig through this simple tutorial "){: width="512" height="493"}
