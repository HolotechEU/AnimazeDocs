# 小道具を使用するにはどうすればよいですか？

Animazeでは、帽子、眼鏡、ヒゲなどの3Dとハイブリッドアバターに装着するカスタマイズ可能なたくさんの小道具を使用できます。次の手順でアバターに小道具を適用します:

1.左メニューの「小道具」ボタンをクリックします

2.小道具ドロワーが開きます。ドロワーには、カテゴリーごとに分けられたアイテムが入っています：帽子、ヘッドホン、眼鏡、ヒゲ、握れる物

![Animaze Props types and customizations]({{ '/assets/images/props-8b37856c.png' | relative_url }} "Animaze Props types and customizations"){: width="790" height="718"}

3.小道具をクリックしてアバターに適用します。小道具を完璧に付加するために、サイズと座標軸のスライダーを使用します。小道具の色とテクスチャーをカスタムして、小道具を目立たてましょう（テクスチャーの変更方法は下記を参照）

![Animaze Props types and customization]({{ '/assets/images/props2-6a19ba3d.gif' | relative_url }} "Animaze Props types and customization"){: width="790" height="706"}

4.調整が終わったら「保存」をクリックして、カスタマイズした小道具をアバターに適用します

![Animaze Props types and customization]({{ '/assets/images/props3-bdc40d11.png' | relative_url }} "Animaze Props types and customization"){: width="790" height="746"}

カスタムテクスチャーの追加方法について詳しくは、小道具の[テクスチャーの変更のFAQ](https://www.animaze.us/faq/animazedesktop/proptexture)を参照してください。

 やっぱりアバターに小道具を使用したくないと思った場合は、ボタンをクリックして全てキャンセルすることが可能です：

![Animaze Props types and customization]({{ '/assets/images/props4-f01f93fa.png' | relative_url }} "Animaze Props types and customization"){: width="790" height="739"}
