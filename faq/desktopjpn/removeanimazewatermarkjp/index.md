# Animazeのウォーターマークを削除する方法

この機能を使用するにはサブスクリプションの登録が必要です。サブスクリプションにまだ登録していない場合、[こちら]({{ '/faq/animazedesktop/howdoisubscribejp/' | relative_url }})から登録方法を参照してください。

1. Animazeメニューボタンをクリックし、設定を設定します

![]({{ '/assets/images/01_7-007147c4.png' | relative_url }}){: width="800" height="509"}

2. Animazeのウォーターマークを非表示にするをオンにします

![]({{ '/assets/images/02_7-fd75dcef.png' | relative_url }}){: width="800" height="532"}
