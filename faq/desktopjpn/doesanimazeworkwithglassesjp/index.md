# Animazeは眼鏡を付けていても使用できますか?

はい、眼鏡を付けていてもAnimazeを使用できます。 

しかし、Animazeの顔識別ソフトウェアでは、眉毛と目が重要な情報として使用されます。そのため、できるだけ薄いフレームの眼鏡を選び、眉毛とフレームができるだけ重ならないようにしてください。また、眼鏡のレンズに光が強く反射しないようにライティングを調整してください。レンズへの反射によってトラッカーが正しく動作しない場合があります。調整後も正しく動作しない場合でも、Animazeで実際の顔が配信されることはありません。
