# Animaze Desktop: System Requirements

All recommendations take into account a few factors:

- avatars, props and scenes are Holotech Originals. **Custom items with very large textures (4k/8k\+), high polygon count or too many blendshapes/animations will affect loading time and overall CPU/GPU usage.**
- webcam resolution is set to the default resolution of 640x480, optimal for accuracy and CPU usage. **Going above 720p resolution will heavily impact CPU usage.**
- Animaze window size set to a max 1920x1080.
