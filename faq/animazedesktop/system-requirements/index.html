Animaze Desktop: System Requirements

All recommendations take into account a few factors:

  • avatars, props and scenes are Holotech Originals. Custom items with very large textures (4k/8k+), high polygon count or too many blendshapes/animations will affect loading time and overall CPU/GPU usage.
  • webcam resolution is set to the default resolution of 640x480, optimal for accuracy and CPU usage. Going above 720p resolution will heavily impact CPU usage.
  • Animaze window size set to a max 1920x1080.

Basic Usage (Animaze + Animaze Virtual Camera in OBS or other teleconference apps)

MINIMUM RECOMMENDED
Operating System Windows 10 Windows 10
Processor Intel® Core™ i5-4570 3.2 GHz or equivalent Intel® Core™ i5-6600 3.3 GHz or equivalent
Memory 2 GB RAM 4 GB RAM
Graphics NVIDIA GeForce GTX 760 or equivalent (support for OpenGL 4.3) NVIDIA GeForce GTX 980 or equivalent
Network Broadband Internet connection Broadband Internet connection
Storage 4 GB available space 4 GB available space
Additional Notes For image based tracking you need a webcam. The requirements are based on desktop systems, not mobile (netbooks, ultrabooks, laptops, tablet pc). The mobile versions of processors and graphics adapters are not equivalent to the desktop ones.
