# Animaze Desktop: What can I do if Animaze doesn’t install/launch?

If you are having trouble installing Animaze (or getting it to successfully launch), don’t worry - there are a couple of fixes for the most common causes of this issue.

When trying to open Animaze, some antivirus software, including Windows’s security, may block the app. All we need to do is whitelist the app in your security software to allow it to install and/or launch.

To Whitelist Animaze in Windows’s Security, follow the steps below:

1. Press the Windows Key and type in Windows Security

![Learn how to troubleshoot Animaze by FaceRig through this simple tutorial ]({{ '/assets/images/not_installing_1-0d767897.png' | relative_url }} "Learn how to troubleshoot Animaze by FaceRig through this simple tutorial "){: width="313" height="180"}

2. Click on Virus & threat protection

![Learn how to troubleshoot Animaze by FaceRig through this simple tutorial ]({{ '/assets/images/not_installing_2-8be285ac.png' | relative_url }} "Learn how to troubleshoot Animaze by FaceRig through this simple tutorial "){: width="292" height="317"}

3. Under Virus & threat protection settings, select Manage settings

![Learn how to troubleshoot Animaze by FaceRig through this simple tutorial ]({{ '/assets/images/not_installing_3-8b4870a5.png' | relative_url }} "Learn how to troubleshoot Animaze by FaceRig through this simple tutorial "){: width="377" height="113"}

4.  Under Exclusions, select Add or Remove Exclusions

![Learn how to troubleshoot Animaze by FaceRig through this simple tutorial ]({{ '/assets/images/not_installing_4-8e1cbc6e.png' | relative_url }} "Learn how to troubleshoot Animaze by FaceRig through this simple tutorial "){: width="507" height="148"}

5. Click Add an Exclusion, click folder, and then browse to Animaze’s installation folder. The default installation folder is C:\\Program Files (x86)\\Steam\\steamapps\\common\\Animaze.

![Learn how to troubleshoot Animaze by FaceRig through this simple tutorial ]({{ '/assets/images/not_installing_5-d9916178.png' | relative_url }} "Learn how to troubleshoot Animaze by FaceRig through this simple tutorial "){: width="516" height="343"}

![Learn how to troubleshoot Animaze by FaceRig through this simple tutorial ]({{ '/assets/images/not_installing_6-44f2e4cf.png' | relative_url }} "Learn how to troubleshoot Animaze by FaceRig through this simple tutorial "){: width="487" height="143"}

6. Click Add an Exclusion again, click ‘File’, and then find Animaze’s executable file (AnimazeDesktop.exe). The default location is C:\\Program Files (x86)\\Steam\\steamapps\\common\\Animaze\\Bin\\AnimazeDesktop.exe

![Learn how to troubleshoot Animaze by FaceRig through this simple tutorial ]({{ '/assets/images/not_installing_7-86ace08f.png' | relative_url }} "Learn how to troubleshoot Animaze by FaceRig through this simple tutorial "){: width="481" height="175"}

Please note, for this FAQ, we use Avast antivirus software as an example. The steps are similar for most antivirus software, so you can use them as such.

1. Launch Avast

2. Go to Avast’s Settings

3. Click on the General tab

4. Click on Exceptions 

5. Click on Add Exceptions and browse for Animaze and add it as an exception. If you can, make sure you whitelist the Animaze executable file (AnimazeDesktop.exe) as well as the Animaze installation folder.

Additional Note: If you use security software to block traffic from specific countries, make sure that you allow traffic from Germany. Some of Animaze’s servers are located in Germany; if that traffic is Geo-blocked Animaze will not function.
