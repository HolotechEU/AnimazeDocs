# Animaze Desktop: How to remove the Animaze watermark

This feature requires a subscription. If you haven’t subscribed yet, find out how to subscribe [here]({{ '/faq/animazedesktop/howdoisubscribe/' | relative_url }}).

1. Open the Menu and choose Settings

![]({{ '/assets/images/01_7-007147c4.png' | relative_url }}){: width="800" height="509"}

2. Toggle the button for Hide Animaze Watermark

![]({{ '/assets/images/02_7-fd75dcef.png' | relative_url }}){: width="800" height="532"}

Alternatively, you can do the same procedure from the Account button as well from the Main Menu

![]({{ '/assets/images/03_4-70a09fe8.png' | relative_url }}){: width="800" height="623"}
