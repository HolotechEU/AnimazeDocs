# How can I create an avatar bundle in Animaze Editor?

In the Animaze Editor, click Hierarchy Panel to the left and then right click on the avatar’s name and choose Bundle

![](https://lh3.googleusercontent.com/7kbB2maimQOeH2hqhsoiesE5w3SwcuOvi4lNQNvDNSegydKlzxNWmureGry9NaE-yRNzLsqjTSDe6FGx-6MyVwpTTGVJg_Cmehs2K1ntqomXAGoYTGZ80kuEAwRAUgAL3z8TvV1X){: width="800" height="426"}

A new window will prompt you to save the changes, if any, made to the avatar prior to bundling it.

![](https://lh4.googleusercontent.com/W56sMjH3ZN-jdBlzKpSZ2-CpA1pzMWeyKq5fc87FvAbWHFot0KAkPNVuuaMGWW4yNnS-MQTKfUUST700x0ctvePC9TsRqhELcT_u5z41tynbsf5qDRsFs2C7WlyHgIOGgAQqhghL){: width="800" height="425"}

Select the folder you want to export the bundle in. By default, the system will put it in the Resource directory of the editor, but you can change this at any time. Once you decide, click Select Folder.

![](https://lh4.googleusercontent.com/-eMR04BIWbEDPrGrO-fCOlIsCm_b146TT_C_PtELlAco9FlMtFwNOrwpDF7_K1H8kqw_QEe0vFeDpx9hsN8fdO1tuH6v7dYStfTS2aUbvKZ4F7an9q_oDgzMxhPExuhWlwTXJ1PB){: width="800" height="428"}

The system notifies the progress and the completion of the bundling process. Click OK.
